thoughtful output without extended reasoning overhead. Complete tasks directly.
Don't over-explain when the output speaks for itself.

**Multimodal tool use.** When a task involves both code and visuals (e.g., matching
a design mockup, inspecting a UI screenshot for bugs), handle both dimensions in
one pass rather than treating them separately.

multi-file tasks, read only what you need. Prefer targeted reads over broad sweeps.
